- **不越界**：实际发生变化的区块集合 == 上表声明区块的并集；`chips` 与 `tabs` 两个区块像素零变化，证明 LS1 的位移被底部空白吸收、未波及筛选行与 tab 栏。
- **重叠说明（本组唯一一处，必须知道）**：LS1 是纵向流里的间距改动，其下游所有会话行都整体平移 24px，因此 `row-1` / `row-2` / `rows` 三个区块同时含 LS1 的位移与 LS4/LS5 的局部改动。
  归因方式：**LS1 是纯平移**（行内内容一字未改），**LS4/LS5 是行内内容改动**（底色 / 文案），两者性质不同，同一张分区图里可分别判定。
  上表的 `row-1` = 17212 / `row-2` = 26417 / `rows` = 149076 都是该区块内**全部**缺陷的合计，不是单条缺陷的独立量。

- **v1 忠实度**：`design.png ↔ v1.png` 残余差异 800 / 1339344 px = **0.060%**，只落在撰写笔、放大镜与 4 个 tab 图标的自绘笔画上；7 行会话、分隔线、间距节奏与设计稿逐像素一致。
