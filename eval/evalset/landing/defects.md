# landing — 注入清单（ground truth）

桌面落地页，1280×800 CSS @2x = 2560×1600。**6 处注入：2 难 / 2 中 / 2 易。**

`v1.html` 是忠实实现（误报率对照组），`v2.html` = v1 + 下列 6 处。
本文件是人读版，机器可读版在 `../fixtures.mjs` 的 `DEFECTS.landing`，两者数值必须一致。

## 清单

## 注入纪律核验

`node ../assert.mjs landing` 的实测输出，三层断言全通过：

| ID | 字符串锚点 | 声明区块内 v1↔v2 变化像素 |
|---|---|---|
| L1 | ✓ v1 恰 1 次 / v2 0 次 | `hero-head` = 34174 |
| L2 | ✓ | `seam-features-cta` = 325795，`cta` = 242219 |
| L3 | ✓ | `feature-2` = 663，`features` = 33654 |
| L4 | ✓ | `feature-1` = 16494，`feature-3` = 16497，`features` = 33654 |
| L5 | ✓ | `nav` = 14775 |
| L6 | ✓ | `hero-actions` = 325 |

- **不越界**：实际发生变化的区块集合 == 上表声明区块的并集，无未声明区块被改动。
- **无重叠**：6 处缺陷的归因区块互不相同。L2 的位移只影响其下方（页面底部空白），不触及特性卡；L3 与 L4 分处不同卡片。
- `features` 一行的 33654 是 L3 与 L4 之和（两者都落在这个大区块内），单卡数字才是各自的独立量。
- **v1 ↔ v2 HTML diff：41 行**（其中 4 行是 `<title>` 与顶部注释的版本标记，各 2 行；其余 37 行为 6 处缺陷本身。L4 是整卡对调，天然占 24 行）。
- **v1 忠实度**：`design.png ↔ v1.png` 残余差异 7592 / 4096000 px = **0.185%**，集中在自绘图标笔画与文字亚像素度量，无位置/尺寸/颜色层面的偏差。
