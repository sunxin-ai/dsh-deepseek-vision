# dashboard — 注入清单（ground truth）

桌面数据看板，1280×800 CSS @2x = 2560×1600。**6 处注入：2 难 / 2 中 / 2 易。**

`v1.html` 是忠实实现（误报率对照组），`v2.html` = v1 + 下列 6 处。
本文件是人读版，机器可读版在 `../fixtures.mjs` 的 `DEFECTS.dashboard`，两者数值必须一致。

## 注入纪律核验

`node ../assert.mjs dashboard` 的实测输出，三层断言全通过：

| ID | 字符串锚点 | 声明区块内 v1↔v2 变化像素 |
|---|---|---|
| D1 | ✓ v1 恰 1 次 / v2 0 次 | `metric-3` = 6384，`metrics` = 11910 |
| D2 | ✓ | `chart` = 594 |
| D3 | ✓ | `metric-1` = 4248，`metrics` = 11910 |
| D4 | ✓ | `table` = 20636 |
| D5 | ✓ | `metric-4` = 1278，`metrics` = 11910 |
| D6 | ✓ | `sidebar` = 28148 |

- **不越界**：实际发生变化的区块集合 == 上表声明区块的并集，无未声明区块被改动。
- **无重叠**：6 处缺陷分落 5 个互不相交的归因区块（`metric-1` / `metric-3` / `metric-4` / `chart` / `table` / `sidebar`）。`metrics` = 11910 是 D1+D3+D5 三者在这个大区块内的合计，单卡数字才是各自的独立量。
- D2 只有 594 px 变化——圆角改动天然只影响四个角，这正是难档该有的量级；分区送检时必须用 `chart` 区块图，整页降采样后基本不可见。
- **v1 ↔ v2 HTML diff：20 行**（其中 4 行是版本标记；其余 16 行为 6 处缺陷，D4 整列对调占 8 行）。
- **v1 忠实度**：`design.png ↔ v1.png` 残余差异 2550 / 4096000 px = **0.062%**，全部集中在侧栏自绘线性图标的笔画差异。
